# منظومة التحضير الجامعي الذكي (Smart QR Attendance System)

نظام متكامل لتسجيل حضور الطلبة يعتمد على الرموز ثنائية الأبعاد المتغيرة (Dynamic Time-based QR) والتحقق الجغرافي (Geofencing) مع اتصال فوري بشاشة العرض عبر WebSockets، محصن ضد التحضير بالنيابة (Proxy Attendance).

## المكونات التقنية
- **الخادم الخلفي:** Node.js, Express, Socket.io
- **قاعدة البيانات:** SQLite3 مع تفعيل نمط WAL (Write-Ahead Logging) لتحمل الوصول المتزامن.
- **طبقة الأمان:**
  - توليد رمز ديناميكي بتشفير HMAC-SHA256 يتجدد كل 10 ثوانٍ لمنع تداول لقطات الشاشة.
  - مطابقة إحداثيات GPS بمعادلة Haversine للتأكد من وجود الطالب بالقاعة.
  - بصمة عتاد مركبة (Canvas + System Fingerprint) تمنع تسجيل أكثر من طالب من نفس الهاتف.
  - لوحة تحكم إدارية محمية برمز PIN وتوثيق التوكنات المشفرة.
